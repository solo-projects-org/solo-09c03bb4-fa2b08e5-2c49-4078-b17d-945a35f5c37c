## 发布语义

- 每个批次的原档保存于 `data/originals/<batch_id>/original.csv`，与判定在同一 SQLite 事务中提交。
- 查询页与下载接口按船舶 `version` 取快照：并发上传或重启后只会看到完整版本。
- 若整个文件没有任何可接受行，接口返回 422，批次不发布，既有航迹不受影响。
